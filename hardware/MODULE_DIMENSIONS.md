## 2. 已发现的资料冲突

1. **OLED 新旧版本不同。** 新款图标 SSD1315，针序 GND、VDD、SCL、SDA；同页旧款电源针序不同。固件兼容性需按新款测试，不能把 SSD1306 库默认成功当作验证。
2. **电池混合销售。** 所购描述为 5V / 3000mAh；详情尺寸与放电大电流表主要针对 12V 组。赠送“2A 充电线”不能证明输出可持续供电 2A。
3. **N20 参数混合。** 6V / 1000 转 / 10 mm 轴长没有匹配电机本体图，不能移用同页其他电压和减速比的尺寸、电流或速度。
4. **ASR02 与小模块不能混用尺寸。** 清单是带下载器的整板，页面 21 × 15 的 SU-03T 参数不足以确定整板孔位。
5. **GY-530 尺寸图冲突。** 图中“25.000”箭头位置看起来跨两安装孔中心，而表格把 25.00 写为 PCB 尺寸；“19.304”的箭头跨中间矩形区域，不能当作两安装孔距。需实测总宽和孔中心距，暂以 **40 × 20 的设计避让框**容纳，后者只是规划空间。
6. **GY-530 针序冲突。** 照片丝印最后两脚为 GPIO1、XSHUT，表格却按 XSHUT、GPIO1 列举。线束只在按实物丝印、导通测试确认后编号。
7. **地址位宽不同。** GY-530 商家写 0x52，为包含读写位的地址字节；Arduino Wire 使用七位地址，应规划为 **0x29**。来源为 [ST 数据手册 §4](https://www.st.com/resource/en/datasheet/vl53l0x.pdf)。

## 3. 电气基线修订

| 对象 | 当前证据与设计处理 |
|---|---|
| 主电源 | 本次按清单的 **受保护 5V 输出**规划输入；不把电池内部电芯端直接接主板。旧文档的 12V 供电只是历史方案 |
| 电机 | 清单是 6V，首轮拟以 5V VM 限占空比测试；转速/扭矩没有保证。若必须额定 6V，另评估升压、峰值电流和回灌处理 |
| TB6612FNG | 逻辑 VCC 拟用 3.3V；VM 拟用 5V。额定能力依据东芝手册与模块散热验证，不能以峰值 3.2A 作为连续堵转能力 |
| DHT11 / BH1750 / GY-521 | 商家分别写 3.3–5.5V、3–5V、3–5V；拟先在 3.3V 条件下逐模块验证，同时检查模块 LDO 压降与上拉电压 |
| OLED | 同图同时有 VDD 3.3–5V 与“工作电压 3.5V”的表述；电源和 I²C 上拉须实测，暂不放行供电封装 |
| GY-530 | 模块 VIN 标 3–5V，板载稳压/转换需核对。XSHUT 不直接推挽驱动到未知电压域，预留开漏下拉接口 |
| ASR02 | 完整主板的供电、电平和峰值音频电流尚未证实。预留独立 5V 电源支路及串口电平适配位置 |
| 两路 LED | 用户已确认普通单颗指示 LED；每路独立 GPIO 和 1kΩ 串联电阻，使用 3.3V，最大理论电流小于 3.3mA/路；颜色与正向压降待选 |
| 早期 12V 电池 / 转换模块 / 红外模块 | 本次链接没有完成其确认。12V 器件不进入本版 5V 输入方案；红外仍保留待确认项与接口，不伪称已配置防跌落 |

## 4. 冻结 PCB 前的实物测量

- ESP8266：外形、排针两列中心距、沿列间距、完整针序、USB 插拔包络、板底元件及天线范围。
- 驱动板：两列排针几何、VCC/VM/GND/控制/输出的逐针顺序，STBY 有无板载上拉。
- 5V 电源：长宽高、输出角色与极性、线缆伸出/弯曲、连续和启动电流、低负载断电及回灌特性。
- 6V 电机/座：完整外形、孔距、轴中心高、安装后轴外露长度、堵转数据与轮毂匹配。
- ASR02 与喇叭：整板外形/孔位/USB 包络、麦克风位置、UART 电平、扬声器外径与固定方式。
- GY-530：总宽、孔距、孔径、针序和光学中心；其余传感器补齐孔坐标、厚度与焊针高度。

这些缺项不妨碍功能分区与逻辑网络规划，但会阻止最终模块插座、安装孔、线宽和生产输出放行。
