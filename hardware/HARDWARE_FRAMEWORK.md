# 硬件框架与布局概念设计

- 项目：ESP8266 两轮桌面机器人
- 文档状态：概念设计，待模块实物确认
- 版本：0.1

## 1. 设计目标
- 用模块化 PCB 和可拆卸连接器替代洞洞板上的大量手工接线。
- 将主控、电源、驱动、传感器与显示功能清晰分区。
- 将电机功率回路与逻辑/传感器信号分开，降低干扰和复位风险。
- 预留调试接口、电源测试点和后续扩展空间。
- 先完成可验证的底盘，再定型外壳。

## 3. 机械结构概念

建议采用分层结构：

1. **底盘层**：安装左右减速电机、驱动轮、万向轮和电池。
2. **电子层**：固定主 PCB、主控、驱动模块和 DC-DC。
3. **前面板层**：OLED 朝向机器人正面，预留红外传感器窗口。
4. **传感器位**：MPU6050 平整固定；DHT11 通风并远离热源。
5. **外壳层（后续）**：为 OLED、USB、开关、充电口、线束和天线留出空间。

初步尺寸仅供摆放推演：底盘约 160 × 120 mm、主 PCB 约 110 × 80 mm、总高度约 80–100 mm 起。最终必须按实际电机、电池、轮子、万向轮和模块尺寸修订，不能直接据此下单。

| 测试点 | 板边或易接触处 | 预留 BAT、5V、3V3、GND |

## 5. 电源架构

电池组 → BMS/电池保护（按电池配置）→ 主保险丝和主开关 → 电源分配点。

电源分配点分为两路：
- 电机支路：电池电压在驱动器允许范围内时，供给驱动板 VM/VIN，再驱动左右电机。
- 逻辑支路：通过 DC-DC 转换为主控和传感器所需电压。ESP8266 开发板、OLED、MPU6050、DHT11 和红外模块各自的供电都必须按实物规格确认。

### 电源安全与兼容性
- 电池正极入口先经过合适的保险丝和主开关，再分配到驱动与 DC-DC 支路。
- 电机供电和逻辑供电分开布线；共地时避免电机大电流流经主控或传感器细地线。
- 电源线宽、铜厚、端子和保险丝规格须依据启动/堵转电流与允许温升计算。
- 按器件手册在电源入口、DC-DC 输出和驱动模块附近布置储能/去耦电容。
- 电机线应与 I²C/传感器线分开；必要时按实测增加电机抑制措施。
- 首次上电先不接电机，测量各路电源与极性后，再逐步连接模块。

### 电池电压必须核实
“12V 锂电池”不能唯一确定满电电压。常见 3S 锂离子电池满电约 12.6V，4S 满电约 16.8V；以实际电池化学体系、串数和充电规格为准。

必须核对驱动板电机电源上限和电机堵转电流。例如 TB6612FNG 的电机电源额定上限约为 13.5V，未确认电池满电电压前不能默认直接接入。保险丝应按堵转电流、启动特性、线材与连接器额定值选取。电池应配套合适的 BMS/保护电路和充电器。

## 6. 接口规划（暂定）

| 编号 | 功能 | 计划信号/说明 |
|---|---|---|
| J1 | 电池输入 | BAT+, GND；防反接设计待定 |
| J2 | 左电机 | M_L+, M_L-；接驱动器输出 |
| J3 | 右电机 | M_R+, M_R-；接驱动器输出 |
| J4 | ESP8266 | 电源、GND、GPIO/UART；按板型定义 |
| J5 | OLED | I²C 或 SPI，待实物确认 |
| J6 | MPU6050 | I²C 方案：VCC、GND、SDA、SCL |
| J7 | DHT11 | VCC、DATA、GND |
| J8/J9 | 左/右红外 | VCC、GND、OUT/其他信号，按模块定义 |
| J10 | 调试串口 | 3.3V UART TX、RX、GND；勿误接 5V UART |
| TP1–TP4 | 电源测试点 | BAT、5V、3V3、GND |

接口编号和信号顺序只是规划。原理图、PCB 丝印和线束表必须核对实物引脚顺序。

## 7. 电气兼容性检查

| 项目 | 检查内容 |
|---|---|
| ESP8266 GPIO | 3.3V 逻辑，不耐受 5V 输入 |
| 红外模块 | 若 5V 供电，确认 OUT 高电平；5V 输出需电平转换/分压 |
| MPU6050 | 核对稳压器、电平转换与 I²C 上拉电压 |
| OLED | 核对 I²C/SPI、供电、引脚顺序和上拉电压 |
| DHT11 | 核对模块版本、供电和数据线上拉 |
| 电机驱动 | 核对逻辑电压、VM 范围、连续/峰值电流与堵转电流 |
| DC-DC | 核对输入范围、输出电压、连续电流、散热与纹波 |

## 8. PCB 工艺建议
- 首版可考虑双层 FR-4、1.6 mm 板厚；铜厚按电流需求选择。
- 安装孔周围留足板边距，避免螺丝或铜柱压到走线。
- 大电流区域采用短而宽的走线/铺铜，逻辑区与功率区分开。
- I²C 走线尽量短，避免与电机输出线长距离平行。
- 大电流连接器需满足电流要求并标明极性。
- 完成 ERC/DRC 后输出 Gerber、钻孔文件、BOM 和装配图；首板上电前检查短路、极性和引脚映射。

## 9. 实施步骤与待办
1. 收集所有模块正反面照片、尺寸、型号和引脚信息。
2. 确认电池串数/满电电压、BMS、电机堵转电流、驱动板额定值和 DC-DC 规格。
3. 完成底盘和 OLED 前面板布局，检查机械干涉。
4. 绘制原理图并审核供电和逻辑电平。
5. 按实物建立封装、布局布线并做 ERC/DRC。
6. 打样后分阶段上电，记录电压、传感器、电机、无线通信、续航和温升结果。
