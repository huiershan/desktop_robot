# 原理图连接与网络说明

版本 concept-0.2，2026-10-24。以下是**可审核的逻辑连接规划**，并非通过 ERC 的 EDA 原理图；模块排针物理编号及未选器件必须在正式原理图中补全。

总览：[连接图](diagrams/schematic_connections.svg)；逐点网络：[CSV](layout/logical_nets.csv)；单一配置源：[plan.json](layout/plan.json)。

## 1. 本版供电基线

采用用户清单所述受保护 **5V 输出电源**，不采用早期“12V 电池直接供电”方案。主板 J1 仅接经确认的 5V 输出，不能接电芯原始端或 12V。充电仍使用电源配套的原有接口，不在此板增加未经确认的充电电路。

逻辑网络：

```text
J1 5V_IN -> F1 -> SW1 主开关 -> PROTECT5V 输入保护 -> 5V_PROT 分配
  +-> VM_PROTECTION（隔离/回灌与滤波待设计）-> 5V_VM -> TB6612 VM
  +-> JP_USB_SAFE -> NodeMCU VIN -> 板载稳压 -> 3V3_LOGIC
  +-> ASR_FILTER -> 5V_ASR -> ASR02（供电资格待实测）
所有 GND 同网；功率回流就近回入口，信号下方保留连续地参考。
```

- F1、线材、开关、保护器件、端子和铜宽的额定值依 **两电机同时启动/堵转、逻辑与扬声器峰值电流**核算，目前不填虚构安培数。
- TB6612 的 VCC 用 3V3_LOGIC，VM 用独立 5V_VM；不得将 VCC 与 VM 默认短接。按实物检查板载跳线。
- 电机额定 6V，5V 驱动只是低压试验方案，不能承诺原标称转速与扭矩。避免为追求转速直接加入 12V。
- VM 侧预留储能、去耦及经核算的瞬态钳位/回灌路径；保护电源未必能吸收制动能量，保护板和保险丝不能替代该设计。
- 本版暂从 NodeMCU 取 3V3_LOGIC，**以板载稳压器电流、压降和温升实测通过为条件**。需要给 ESP8266 自身峰值留余量。若不满足，应修订为经过隔离验证的外部稳压方案，不能并联两个 3.3V 稳压器输出。
- USB 供电隔离是放行条件。未确认克隆板电源路径前，连接 PC USB 时先断开 JP_USB_SAFE，并按台架步骤验证其余支路供电；不得把 VU/USB5V 当成已验证可回灌的输入。
- ASR02 主板有自身 USB 下载器，其 USB 与主板 5V 的隔离同样待验证；不要依靠通信线给断电模块反向供电。
- TP_IN、TP_5V、TP_VM、TP_3V3、TP_GND 分别设置于保护前后和负载端；所有电源测试点标明电压与极性。

## 2. 引脚资源与拟新增 U2

若 TB6612 全部控制脚、I²C、DHT、串口和两路 LED 都直连，ESP8266 的可用脚不足且会占用启动绑带/下载资源。本版提出新增 **SC16IS750IPW**，同时提供 I²C UART 和 GPIO：

- U2.GPIO0..3 分别驱动 AIN1、AIN2、BIN1、BIN2；方向更新前先停止 PWM 并拉低 STBY。
- U2 的 UART 经电平适配接 ASR02，避免与 NodeMCU 板载 CH340 的 TX 输出并联。
- U2.GPIO4 经开漏下拉级控制 ToF XSHUT；GPIO5/6 供两路数字红外候选输入，GPIO7 预留。
- U2 VDD=3.3V；I2C/SPI 选择脚、A0、A1 均接 VDD；规划七位地址 **0x48**。UART 需要独立时钟/晶振及匹配电容，频率、负载、复位外围按最终波特率和 NXP 手册确定。
- SC16IS740 缺少这些 GPIO，不能替换。U2 是新增设计物料，尚未采购，也没有驱动验证。
- RESET、时钟和各电源去耦须在正式原理图补齐；逻辑 CSV 没有表达芯片全部电源/未用脚，不可导入后直接当成完整网表。

两路电机 PWM、MOTOR_ARM 与 LED 均直接由主控控制，具体表见 [GPIO 规划](../software/PIN_MAPPING.md)。

## 3. 电机停止路径

```text
GPIO15 -> R_ARM 1kΩ（初选）-> SW_MOTOR 手动允许开关 -> U4.STBY
U4.STBY -> R_STBY 10kΩ（初选）-> GND
GPIO12 -> PWMA；GPIO14 -> PWMB；各预留 10kΩ 下拉
```

- GPIO15 启动需为低，STBY 不得被模块自身上拉破坏这一条件；必要时先拆除模块上拉/增加适配，未核验前不接电机。
- SW_MOTOR **断开**时，驱动器侧下拉使 STBY 为低；它是独立的运动禁用开关，不替代主电源开关或认证急停装置。
- 启动顺序：先 STBY=0、PWM=0，再验证 U2、设方向、验证传感器及命令，最后允许 STBY。故障时先 GPIO15=0、PWM=0，日志和 I²C 重试排在后面。
- U2 输入有内部上拉，不能假定复位后方向脚都是低；必须在 STBY 保持低时写 IOState/IODir 并回读。下拉值要结合内部上拉核算。
- ESP 复位而 U2 保持原方向时仍须由 GPIO15 下拉禁止运动；台架验证看门狗、复位、I²C 卡死、拔线和手动开关。
- 东芝真值表中 STBY=0 为高阻待机，PWM=0 与短路制动相关，二者不是相同停止方式；实际停车距离和回灌要测试。

## 4. I²C 总线

GPIO4=SDA、GPIO5=SCL，短线共地。初期拟 100kHz，以实测上升沿、线束电容及任务时序决定是否提高。全部主控侧上拉到 3.3V；主板上拉位可不装，先测模块已带电阻，避免并联过强。

| 设备 | Wire 七位地址规划 | 证据状态 |
|---|---|---|
| U2 SC16IS750 | 0x48 | A1/A0 均接 VDD 的设计选择 |
| OLED SSD1315 | 0x3C 候选 | 实物扫描待做 |
| MPU6050 | 0x68，或 AD0 高时 0x69 | 原厂定义；核对模块绑带并扫描 |
| BH1750 | 0x23 候选 | ADDR 及实物扫描待做 |
| VL53L0X | 0x29 | ST 的 0x52 地址字节右移一位；实物扫描待做 |

GY-530 的 VIN 支持范围不代表 XSHUT/GPIO1 耐受 5V。Q_XSHUT 用开漏下拉，只允许下拉或释放，释放侧上拉必须接模块允许的电压域；电平不明前不装跳线。暂不使用 GPIO1，保持不接。

## 5. DHT11 与 LED

- DHT_DATA 拟用 GPIO2，数据上拉至 3.3V，电阻值结合模块已有上拉核对。GPIO2 是启动绑带脚，需验证冷启动和传感器故障时的电平；不满足即调整资源规划，不能直接放行。
- DHT11 拟采用不短于 2s 的保守采样间隔，最终以实际版本手册为准。它不是 I²C 设备，不能挂到 U2 GPIO 当作实时单总线替代。
- 用户明确两路是**普通单颗指示 LED**：GPIO13→R_LED1=1kΩ→J11.1→LED 阳极，LED 阴极→J11.2/GND；GPIO16 同理接 J12。
- 两路独立限流；I≈(GPIO高电平−LED正向压降)/1kΩ，不接裸 LED 短路 GPIO，也不用于灯带或大功率 LED。GPIO 侧提供测试点，开机固件先写低再设输出。
- GPIO16 可能与开发板用户灯共用；板载灯、电平极性及启动闪烁待实测。本版不依赖 GPIO16 的硬件中断或调光 PWM。

## 6. 串口、红外与调度约束

- UART0 GPIO1/3 保留 USB 下载和日志。ASR02 TX/RX 只通过 U2 的 UART；通信 TX/RX 必须交叉，电平适配与供电顺序验证后才能接通。
- ASR02 整板协议、波特率与电平待确认；初版候选为 9600 波特的短命令，不能当作卖家默认值。U2 FIFO 64 字节，8N1 下填满时间约 `64×10/baud` 秒，轮询最坏间隔必须留足裕量。
- OLED 不得一次长时间独占总线。规划 16 字节级分块和限时 I²C 操作；结合 UART FIFO、DHT 临界区和电机周期测量主循环最大停顿。
- J8/J9 只是两路红外候选接口；没有链接确认其数量、数字/模拟输出、电压和有效极性。电平适配与供电选择在确认前不装；模拟型号需要另评估 ADC。
- 前向 ToF 不能替代向下防跌落传感器。自动桌面运动须等防跌落覆盖、停止距离和故障路径实测通过；此前仅做抬轮或受控台架测试。
- 本版没有电池分压采样网络，A0 保留，不提供虚假电量数据。
