- [ ] 所有模块排针高度、孔位、公差与底部元件核对。
- [ ] 电池持续/峰值电流、低负载维持、充电限制与回灌能力核对。
- [ ] 两电机启动/堵转电流、TB6612 工作条件与温升通过。
- [ ] 5V主干/VM支路/语音峰值及3.3V稳压余量和热预算完成。
- [ ] USB/VIN/VU 与 ASR USB 供电隔离方案验证，无双源硬并联和反向供电。
- [ ] 普通LED颜色、极性、实际亮度和限流电阻功耗确认。
- [ ] 两路下视红外的型号/数量/逻辑/距离确认，接口适配完成。
- [ ] 选择全部连接器准确料号、锁扣、键位、额定值与真实封装。

## 正式原理图 / ERC

- [ ] 将逻辑网转换为完整 EDA 器件，补齐全部电源、复位、时钟、NC 与适配外围。
- [ ] U2 必须是带 GPIO 的 SC16IS750/760 合格选型；型号替换重新审核。
- [ ] 核对 SC16IS750 的 A0/A1、模式、RESET、IRQ 上拉、晶振与 GPIO 初态。
- [ ] STBY 默认低，GPIO15 启动条件成立；GPIO2 的 DHT 上拉与失败状态不破坏启动。
- [ ] GPIO6–11 未被分配，UART0 与 CH340/ASR 没有推挽输出并接。
- [ ] I²C 主控侧3.3V上拉、电阻并联值与电平适配核算。
- [ ] XSHUT 只下拉/释放；UART与红外的高电平上限和供电顺序核对。
- [ ] VM储能、回灌、钳位、电容耐压、保护热能力和保险配合完成。
- [ ] 连续GND与功率回流方案审核，所有模块电源去耦齐全。
- [ ] ERC零未处理错误；例外逐项说明与签字，保存工具版本和报告。

## 布局 / DRC / 机械

- [ ] 导入经核对的模块封装；在纸质1:1打印或实物模板上插板试配。
- [ ] 连接器壳体、线束弯曲、USB插头和手指拔插空间无干涉。
- [ ] 天线真实净空及所有层禁铜、金属/电池/喇叭三维避让完成。
- [ ] 孔径、板边距、螺丝头、垫片、铜柱与铜箔距离完成。
- [ ] OLED窗口偏移、固定与玻璃避压完成；ToF视窗/串扰校准位置确认。
- [ ] 钢珠轮垫高量、轮毂插深、两电机轴同高、重心和线束活动检查完成。
- [ ] 电源线宽/铜厚/过孔按电流温升计算，测试点可测，丝印与极性清晰。
- [ ] DRC零未处理错误；保存规则文件、工具版本、报告与未布通网络数。

## 制造与首板

- [ ] 输出可编辑原理图/PCB、审阅PDF、Gerber、钻孔、板框、BOM与装配图，版本一致。
- [ ] CAM逐层复核板框、镀通/非镀通孔、阻焊、丝印、层序和单位。
- [ ] 不接模块/电机时检查短路、极性和各电源；限流电源从低负载上电。
- [ ] 按供电、OLED、I²C各模块、DHT、语音、LED顺序单独测试并记录电流。
