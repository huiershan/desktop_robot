# 连接器与线束规划

concept-0.2，2026-10-24。**下面编号属于主 PCB 的计划接口**，不等于模块原排针序号。所有连接器完整料号、方向、防呆键和封装尚待选型，接线前必须按模块丝印逐针导通核对。

## 1. 主板端针序

| 编号 | 功能 | 主板针序（1 脚起） | 计划系列 / 状态 |
|---|---|---|---|
| J1 | 受保护 5V 电源输入 | 1=5V_IN，2=GND | 与电机/LED 不同系列的带锁电源连接器；电流与料号待定 |
| J2 | 左电机 | 1=AO1，2=AO2 | 电机专用带锁连接器；额定电流依堵转确认 |
| J3 | 右电机 | 1=BO1，2=BO2 | 同 J2；方向由低占空比抬轮测试记录 |
| J4A/J4B | NodeMCU 开发板插座 | 完整针数、逐针与两排几何 **待实测** | 两列母座可拆卸；本版不生成焊盘坐标 |
| J5 | OLED | **1=GND，2=3V3_LOGIC，3=SCL，4=SDA** | 四芯信号接口，拟 GH 1.25；OLED 供电验证后装配 |
| J6 | MPU6050 I²C 线束 | 同 J5 | 同一标准 I²C 针序；模块可在主板中央机械固定 |
| J7 | DHT11 | 1=GND，2=3V3_LOGIC，3=DHT_DATA | 拟 GH 1.25 三芯 |
| J8 | 左下视红外候选 | 1=GND，2=IR_VCC_PENDING，3=IR_L_RAW | 与 DHT 不同系列，拟 XH 2.5 三芯；供电选择和适配先不装 |
| J9 | 右下视红外候选 | 同 J8，3=IR_R_RAW | 同 J8；传感器本体型号尚未确认 |
| J10 | 调试 UART | 1=GND，2=DEBUG_TX，3=DEBUG_RX | 3.3V 测试触点/有明确方向的调试接口，无 5V 电源脚 |
| J11 | 指示 LED1 | **1=LED1_A（经 1kΩ），2=GND** | LED 专用两芯，拟 PH 2.0；与电源、电机防误插 |
| J12 | 指示 LED2 | **1=LED2_A（经 1kΩ），2=GND** | 同 J11，两路独立 |
| J13 | BH1750 | 1=GND，2=3V3_LOGIC，3=SCL，4=SDA，5=ADDR_OPTION | 五芯信号接口；ADDR_OPTION 只作模块端地址绑带选择，默认配置待核对 |
| J14 | ASR02 UART 与电源 | 1=GND，2=5V_ASR，3=ASR_TX（入主板），4=ASR_RX（出主板） | 与 I²C 不同系列的四芯，拟 XH 2.5；电平与主板针序待实物确认 |
| J15 | GY-530 | 1=GND，2=3V3_LOGIC，3=SCL，4=SDA，5=TOF_XSHUT，6=NC | 六芯信号接口；GPIO1 暂不接，XSHUT 经开漏适配 |
| J16 | 主开关引出 | SW1 两端，按负载电流选线束 | 不与低电平开关接口共用系列 |
| J17 | 电机允许开关 | SW_MOTOR 两端 | 断开即由驱动侧下拉禁止 STBY，不承载电机电流 |

GH/PH/XH 是初步连接器系列建议，必须按原厂料号确认真实间距（不能把“XH2.54”卖家名称直接当作标准 2.54mm 封装）。相同芯数但不同电压的接口需采用不可互插结构，不能只靠颜色防错。

## 2. 模块端与主板端映射

| 模块 | 模块丝印 / 接点 | 对应主板信号 | 接线依据 |
|---|---|---|---|
| 新款 OLED | GND / VDD / SCL / SDA | J5.1 / 2 / 3 / 4 | 匹配新款图，不沿用旧款 VCC/GND 顺序 |
| GY-521 | VCC / GND / SCL / SDA | J6.2 / 1 / 3 / 4 | 电源两脚与标准接口次序不同，线束必须换序 |
| GY-521 | AD0、INT、XDA、XCL | AD0 模块端绑带核对；其余暂不接 | 不把悬空脚短接到相邻电源；记录实际 AD0 |
| DHT11 | VCC / GND / DO(DATA) | J7.2 / 1 / 3 | 根据丝印确认，不能按线色猜测 |
| GY-302 | VCC / GND / SCL / SDA / ADDR | J13.2 / 1 / 3 / 4 / 5 | ADDR 的默认电平与电阻由实物确认 |
| GY-530 | VIN / GND / SCL / SDA | J15.2 / 1 / 3 / 4 | VIN=3.3V 的模块工作情况待验证 |
| GY-530 | XSHUT | J15.5 | 按实物定位；图片与表格最后两脚次序冲突 |
| GY-530 | GPIO1 | 不接 | 主板 J15.6 也为 NC，线束此芯绝缘/不装端子 |
| ASR02 | 实物 TX / RX / GND / 电源 | J14.3 / 4 / 1 / 2 | TX 是模块输出；U2 TX 到模块 RX。模块原针位未确认，不能发放制作线束 |
| 普通 LED | 长脚/阳极 A，阴极 K | J11 或 J12 的 1→A，2→K | 以实际 LED 极性为准；电阻已在主板上 |
| TB6612 | VM/VCC/GND、各控制脚与 AO/BO | 按同名网络 | 未获得真实模块排针图，先用逻辑信号表，不填物理针号 |

## 3. 装配与验证规则

1. 主板丝印：编号、功能、1 脚、GND、电压和信号方向；线束两端贴相同编号。
2. 从主板顶视与模块正视分别画方向箭头，记录插头锁扣朝向，不能用“从左数”作为唯一依据。
3. 万用表检查每根线的端到端导通、相邻短路、电源/地换序；测试记录后才能接模块。
4. 电机端两根线都不是固定 GND，不接共地线；不得将任一 H 桥输出直接接系统地。
5. 线束走底盘边缘；电机线绞合并远离 I²C、麦克风和天线；留拔插、弯曲半径与应力释放空间。
6. [位置坐标 CSV](layout/connector_positions.csv) 仅给候选参考点，不是钻孔/焊盘中心；必须结合最终连接器壳体做干涉检查。
