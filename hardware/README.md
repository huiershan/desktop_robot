## 设计原则
1. 未确认的尺寸、引脚和电气参数必须标记为待确认。
2. 每个模块记录准确型号、供电范围、逻辑电平、峰值电流和连接器针脚。
3. 原理图完成 ERC，PCB 完成 DRC 后再输出生产文件。
4. 电源/电机功率路径与敏感信号路径分区布线。
5. 接口丝印必须标明信号名、供电电压、极性和 1 脚方向。

> 当前为概念设计阶段，不应直接据此生产 PCB；必须先核对实物和数据手册。
