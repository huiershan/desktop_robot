## 拟新增主板物料

| 参考 | 数量 | 拟选 / 值 | 参数与替代要求 |
|---|---:|---|---|
| U2 | 1 | **SC16IS750IPW** | 新增 I²C UART + 8 GPIO，3.3V，TSSOP24；采用 NXP 原厂封装图。SC16IS740 无 GPIO，不能直接替代 |
| Y1 | 1 | UART 晶振，14.7456MHz 初选 | 最终按波特率、时钟范围、CL/ESR 和器件手册定料 |
| C_Y1/C_Y2 | 2 | 晶振负载电容，待算 | 按晶振 CL 与寄生计算，不能直接复制经验值 |
| C_U2 | 至少 1 | 100nF 初选 | 近 U2 电源脚；完整去耦按手册补齐 |
| R_IRQ / RESET 外围 | 1 组 | 待原理图定案 | IRQ 上拉与 RESET 默认状态按原厂要求；不依赖其完成电机停止 |
| F1 / 保险座 | 1 组 | 熔断或受控限流保护待选 | 同时满足启动不误动作、故障能切断、线材与端子保护要求 |
| SW1 | 1 | 主电源开关，待选 | 额定电流、电压、触点与线束依峰值确认 |
| PROTECT5V | 1 组 | 极性/输入保护，待选 | 5V 压降与温升需核算；不能把 12V 插入保护视为已实现 |
| VM_PROTECTION / C_VM | 1 组 | 功率隔离、滤波、储能与钳位待选 | 验证电机回灌与源端不能吸收能量的情况 |
| JP_USB_SAFE | 1 | 可拆供电跳帽 / 隔离方案 | 先验证 NodeMCU USB/VIN/VU 路径，禁止双路电源硬并联 |
| SW_MOTOR | 1 | 独立运动允许开关 | 断开 STBY 回路；不承载电机 VM 电流 |
| R_ARM | 1 | 1kΩ 初选 | GPIO15 到 STBY 回路串联；结合逻辑门限核对 |
| R_STBY / R_PWMA / R_PWMB | 3 | 10kΩ 初选 | 复位状态与模块板载电阻核算后定案 |
| R_LED1 / R_LED2 | 2 | **1kΩ** | 普通单颗指示 LED，每路独立限流，3.3V GPIO 直接控制 |
| LED1 / LED2 | 2 | 颜色 / 封装待选 | 接线外置或板载选其一；本版不配置灯带或高功率驱动 |
| R_SDA / R_SCL | 2 个位置 | 可不装，候选 4.7kΩ | 先测模块已有上拉，等效值与上升沿合格后装配 |
| R_DHT | 1 个位置 | 按模块已有上拉选择 | 上拉到 3.3V，检查 GPIO2 冷启动 |
| Q_XSHUT 与外围 | 1 组 | 3.3V 门极可驱动的开漏下拉级 | 源接地，漏接模块 XSHUT；不可把未知电压域直接拉到5V |
| UART_LEVEL | 1 组 | 双向通信的两个独立方向适配位 | ASR 的 TX/RX 电压域确认后选型；仅双方兼容时用 0Ω 旁路 |
| IR_LEVEL / IR_SUPPLY_SELECT | 1 组 | 预留，先不装 | 两路输入最终按实际数字/模拟类型定案；不将 5V 直接送入主控/桥接 GPIO |
| J1–J17 / 线束 / 测试点 | 按接口 | 见 [针序表](CONNECTOR_PINOUT.md) | 完整料号、锁扣、极性、额定值、弯曲空间待选型 |
| 主 PCB / 底盘 / 铜柱 / 紧固件 | 各 1 组 | 110 × 80、160 × 120 为候选 | 板框与孔位必须经实物布局复核；本版不提交生产 |

替代料必须重新核对供电、逻辑门限、默认状态、封装和热能力；不能只看名字相近或“可兼容”购买标题。参考图与原厂链接见 [SOURCES.md](SOURCES.md)。
