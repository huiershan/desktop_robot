## 拟新增 SC16IS750

U2 七位 I²C 地址 0x48（A1/A0 接 3.3V），同时提供语音 UART 与方向控制 GPIO，避免再消耗主控引脚。新物料尚未采购，相关 HAL/驱动需后续实现。

| U2 资源 | 分配 |
|---|---|
| GPIO0 / 1 | AIN1 / AIN2 |
| GPIO2 / 3 | BIN1 / BIN2 |
| GPIO4 | ToF XSHUT 的开漏下拉级门控，**不是直接连 XSHUT 推挽** |
| GPIO5 / 6 | 两路已适配成 3.3V 的数字红外候选输入 |
| GPIO7 | 预留输入 |
| TX / RX | 经电平确认/适配交叉连接 ASR02 RX / TX |
| IRQ | 首版轮询，预留测试点；引出或使用时按原厂要求上拉 |

SC16IS740 没有这些 GPIO，不能代用。I²C 总线共享 OLED、MPU6050、BH1750 和 VL53L0X，地址是否有效必须通过扫描与驱动识别确认。

## 软件必须执行的约束

1. 启动先禁止 STBY 并清零 PWM，再做 U2、传感器和命令自检。
2. U2 的方向寄存器写入和回读成功后才允许运动；桥接器或传感器错误时先直接停电机。
3. 软件/看门狗复位不能默认 U2 也复位；方向可能保持，停止仍靠主控 STBY。
4. OLED 分块与日志限流，检查 U2 UART FIFO 溢出和任务最坏延迟；DHT 低频采样。
5. 控制命令超时必须停止；FAULT_STOP 清除后重新自检，不能恢复旧速度。
6. LED 两路独立，不承载运动允许、复位或总线控制职责。

完整电气条件与连接见 [SCHEMATIC_NOTES.md](../hardware/SCHEMATIC_NOTES.md)。
